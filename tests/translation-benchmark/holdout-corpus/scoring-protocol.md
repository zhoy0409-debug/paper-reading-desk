# 独立验收评分协议

105 段来自 7 篇各自允许再分发的原文，每篇 15 段。参考译文、事实、术语、原始 PDF 换行及预选盲评名单在工程侧提交模型输出前独立编制。每段的出处见 `sources.json` 和 `sourceLocator`。文件摘要见 `freeze.json`。参考译文是可以接受的一种表达，允许含义相同的用词、语序、单位写法和标点。

## 输入和复算

匿名实测文件为 UTF-8 JSONL，每个选段一行，固定编号 H001 至 H105。A、B 的真实版本由运行方保存到评审结束。两列含 `translation`（用户实际看到的译文，包括原文回退）、`rawCandidate`（校验前候选，若未记录则留空）、`displayed`（确实向用户展示译文）、`accepted`（校验决策）、`flagged`（用户是否收到准确性或局部保留提示）、`status`。布尔值 `null` 表示未知。`displayed` 必须为布尔值。可选数值为 `latencyMs`、`retries`、`extraActions`，可选条件为 `cacheState`。整列或整条缺失仍进入计划分母，记作缺失。

```text
python score_holdout.py anonymous.jsonl --out scores
python score_holdout.py anonymous.jsonl --out scores --reviews decisions.jsonl
```

第一次运行生成逐项字面命中、汇总和盲评表。U、V 顺序按选段打乱。盲评表提供原文、独立参考、锚点、实际展示文字和单独的原始候选。模型身份、审核放行状态和错误警告均从盲评表中隐藏。审读后单独保存每个选段的 `{id,U,V}`，U、V 分别取填完的 `decision`。第二次运行校验标注的完整性，复原为 A、B 列。评审人员应先对展示译文和原文逐句判断，再对候选作出可接受性判断。候选缺失时记录为 `null`。跟随输出出现的警告在评分表中单独比较。

## 自动筛查

1. **是否显示含中文的结果**。105 个计划选段为分母。须实际展示、有汉字、并与选段原文不同。该指标仅确认显示状态，中文错误提示、英文夹杂或语义颠倒仍需审读。
2. **事实和术语字面命中**。各版本分母分别为 260 个事先标注的事实锚点、177 个术语锚点。命中条件是展示文本中出现预先列出的中文或允许的表达。每个锚点最多计一次，失败及原文回退计零。只统一 Unicode 兼容字形、全角、常见负号及范围线、数值千分位和空白。保留不等号、正负号、大小写和单位，检查数字边界。自动筛查不会判定概念的归属、否定范围或跨句正确性。字面未命中也可能是合格的译法。
3. **时延与操作**。对实际记录的同类请求取最近秩 P50/P95（升序第 ⌈p × n⌉ 个），同时列出测量数。已提供冷、热状态时分别统计。重试次数/额外操作次数逐项加总，仅在实测有值的位置计入操作统计。这 105 条的时延不代替另行控制设备与缓存的性能基准。

## 逐条独立语义审读

| 指标 | 判定和分母 |
| --- | --- |
| 完整且可阅读 | 有连贯的中文表达，覆盖整段内容。必要的化合物本名、缩写和数学符号可保留。缺失整句、主要从句或成段保留英文均计失败。分母是实际审读范围内的所有计划选段，包括翻译失败和没有结果的选段。 |
| 有效内容覆盖 | 按选段计。完整可读且主要科学陈述、比较、条件和限定均可用于科研阅读计 1，部分有效或需读者自己改正主要内容计 0。结果同时给出预选 35 段和全量完成程度。 |
| 事实保留与术语准确 | 对每一条预先标注的事实/术语独立判定。准确表达科学含义和对象计 1。数值即使出现，错配对象、量纲、比较方向或条件也计 0。原文回退计 0。分母是已审读选段的全部锚点。 |
| 严重语义错误 | 用户看到的中文若会改变主要研究结论、对象、比较方向、关键数值/单位、统计显著性、化学身份或因果解释，记一次选段级严重错误。无译文仅计交付失败。低质量措辞与技术性小错单独记录。结合运行时 `flagged` 列区分已警示、未警示和警示状态未知。 |
| 校验误拒 | 已捕获且经独立审读可接受的原始候选中，校验明确拒绝的比例。原始候选、校验决策缺失均不进入此分母，另报不可评估数。 |
| 校验漏判 | 已捕获且经审读不可接受的原始候选中，校验明确通过的比例。与“用户实际看到的译文中有多少错译”使用不同分母。若只拿到通过的候选，要明确可评估范围。 |

逐条理由应指出具体差异，可接受的同义改写应正常给分。预选样本由每篇 5 段组成，覆盖 8 种章节，编号见 `freeze.json`。额外全量审读保留这一固定分层子集，避免根据模型表现临时挑选展示案例。两个版本均由同一位独立评审代理对照原文和核验过的参考检查，未经过第二位人类专业审稿人复核。
