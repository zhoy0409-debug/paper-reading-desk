## 安装、缓存与首次使用

第一次打开划词面板会显示 1.35 GB，点击“下载并设为默认精译”之后才开始下载。可以直接选择轻量快速翻译。已有模型会按块核验，默认使用本机精译。模型缓存全部丢失后需要重新确认。读者的论文和选段留在设备上。[首次确认截图](first-use-size.png) · [同一选区的实际译文](first-translation.png)

| 实测入口 | 结果 |
| --- | --- |
| Chrome 158，发布方真实网络地址 | 确认前模型请求为零。首次下载、启动和把 `water` 译为“水”合计 8 分 14 秒。重新打开阅读器耗时 9.49 秒，模型下载请求为零。[运行记录](runs/publisher-download.json) |
| Windows 便携候选包，Edge 158 | 下载中断后保留 16 MiB，再次点击从该偏移继续。损坏一块后只补取该 8 MiB。完全清除缓存后再次显示大小，未经确认的重新下载请求为零。上传 PDF 后取得了当前词的原句。[运行记录](runs/portable-edge.json) |
| WebKit 26.5 自动化 | 真实 PDF 选词翻译成功。重新加载页面后再次得到“水”，没有重新下载模型。Windows 环境下这次分别耗时 138.2 秒和 58.4 秒，模型源为本机测试文件。真实 Safari 和 iPad 仍未验证。[运行记录](runs/webkit-weights.json) |

Windows 包与公开页面候选构建的 34 项翻译资源逐项比对一致。Chrome、Edge 和 WebKit 的本机模型路径中均未记录到向外部服务发送选段的 POST 请求。正式版网址仍提供既有版本。

## 改动、回归和回退

| 文件 | 技术原因与改动 |
| --- | --- |
| `dist/local-scientific-model.js`、`dist/translation-weight-cache.js` | 记录读者确认与模型保存状态。模型启动时提供 WebKit 可用的存储接口，浏览器缺少文件系统接口时使用 IndexedDB 按块存放二进制数据。模型引擎空闲或失败后释放句柄。 |
| `dist/selection-translation.js`、`dist/translation-session.js`、`dist/translation-context.js` | 首次选择模型、仅重试当前选区和缓存丢失分别给出对应反馈。保存选词所在原句，并优先保留术语和需纠正的问题。 |
| `dist/translation-facts.js`、`dist/translation-claims.js` | 区分功率和能量面密度，允许量纲相同的等价换算。数值唯一对应时可恢复印刷单位，同时保留数值变化或归属不确定的核对提示。修正部分图号、范围、比较和统计显著性的误拦。 |
| `tests/translation-evidence.mjs`、浏览器测试和发布工作流 | 同时测试允许的等义译法和改变科学事实的反例。实际上传 PDF 检验知情下载、断点续传、局部修复及重新确认。当前代码与盲评资产的摘要须吻合才可发布。 |

在上一轮已经用于排障的 8 篇论文上，默认可用从 35/57 升到 51/57，严重错译未经提醒的段数从 2 降到 0。有一段仍把瓦时每平方米译为瓦每平方米，已显示校验提示。曾经暴露问题的材料作为回归，新论文独立计分。[往轮回归实测](runs/third-round-regression.json) · [回归统计](regression-summary.json)
