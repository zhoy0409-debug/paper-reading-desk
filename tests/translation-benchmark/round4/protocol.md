# Fourth scientific translation evaluation

The frozen set contains 48 English selections from eight papers that were absent from earlier rounds. The subjects include positioning, running biomechanics, reading comprehension, hydrology, archaeology, optical imaging, adsorption and visual attention. Source metadata include authors, journal, DOI, license and the JATS file digest. Seven papers use CC BY 4.0 and one uses CC0. The paper sampler fixes six strata per paper before running the translator. It does not use translation outputs or quality scores. [Source records](sources.json) · [Selection script](fresh_sources.py)

The UTF-8 corpus SHA-256 is `deeb69bd9571f02ad615d0fd5150f5e1c077a153462f2c714c4b00407763a2e1`. The evaluated browser code, model manifest, Wasm and translation assets were frozen before opening these outputs. The saved article section rows supply the paper's title, nearby text and locally defined abbreviations to the same session engine used by PDF selection. Section-row positions in this benchmark do not represent PDF page numbers. [Inputs](fresh.jsonl) · [Engine freeze](engine-freeze.json)

Chrome ran the public 0.4.18 reader, the previous local model candidate and the revised candidate on the same selections. The two local candidates use the same pinned model. The test uploads an actual PDF and uses a native text selection for first use and after reopening. Benchmark selections are then supplied directly to the reader session. Both local engines use the same JATS source texts for context. The checked local weight file replaces the network transport for timed model comparisons. The separate publisher-download test measures a real cold transfer. [Browser driver](../../translation-local-model-browser.cjs) · [Publisher download](runs/publisher-download.json)

Identical source–target pairs are deduplicated and assigned a hash key. The bilingual assessment hides version, validation, visible state and latency. A reviewer assesses each original sentence on scientific meaning, population, timing, quantitative evidence and strength of conclusion. Source fallbacks and correct text hidden from the ordinary view do not earn default coverage. These are model-assisted bilingual assessments. There has been no independent human double review of this round. Only after grading are the observed outputs joined to their original reader state. The previous eight-paper set is also rerun as regression material. Its three changed translations were graded again.
