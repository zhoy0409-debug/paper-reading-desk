# Fifth scientific translation evaluation

Eight open articles supplied six selections each. The authors, journal, DOI, source XML digest and licence accompany every article. Seven articles carry CC BY 4.0 and one carries CC0. The original English, section and locator accompany each selection. English excerpts and the translations in this directory are attributed to the corresponding article authors. [Article credits](sources.json) · [Excerpts](fresh.jsonl)

The sampler excluded earlier papers and used a fixed hash ordering within six strata covering abstracts, figure captions, measurements, comparisons, other prose and adjacent sentences. Europe PMC discovery returned a service error, so discovery used the PLOS index. A topic with no eligible matches was replaced with hydrogel before translation. The final sample contains eight topics from one journal. These passages complement earlier multi-journal evaluations. [Sampling script](fresh_sources.py)

The corpus SHA-256 is `7f3be464a6fb43246c02be0d50ff31748c6fe4985cd34fde0a5fe0dce2e8d833`. A manifest of 34 translation assets was frozen before running the new candidate. All versions received the same English selections. Both candidates used paper context derived from the same source XML. Baseline outputs came from the public reader. The two candidate readers ran in Chrome. Native PDF selection, packaged Edge and WebKit runs have separate traces. [Asset digests](engine-freeze.json) · [Browser outputs](runs) · [Paper context extraction](paper_contexts.py)

An engine-blinded, model-assisted review scored 102 distinct original/translation pairs without display status or machine warnings. Each unit received one grade for usable meaning, an ordinary substantive error, a severe scientific error or no output. Grades were then joined to display and warning states. A plausible sentence with reversed regression variables is severe. A general machine warning can prevent a unit from counting as unmarked even when the translation is still wrong. An independent human expert has not graded the pairs. [Anonymous pairs](anonymous.jsonl) · [Grades and reasons](semantic.tsv)

Replay from the repository root with `python tests/translation-benchmark/round5/audit.py verify OUTPUT_DIR`. The `release` action additionally requires at least 98% usable sentences in the default view and zero unmarked severe passages. [Recorded counts](summary.json)

After integration with reader 0.4.19, the reader entry page and PDF reader script changed. The other 32 monitored assets kept their original hashes. A fresh Chrome profile repeated all 48 selections from the same eight papers. The 58 sentence outputs, warnings, display states and paper contexts matched the graded run exactly. The audit compares both runs before using the existing grades.
