# Fresh-paper check

The unit of sampling is a published passage. Six previously unused papers contribute one abstract sentence, figure-caption sentence, measurement sentence, comparison sentence, other body sentence and two-sentence passage apiece. The deterministic sampler and source licenses are included. The SHA-256 of the UTF-8 input is `a5c18cd25a97c0bbca3c2630203dc8228b546247f01f6aeb31e5ede6e1c2cc8a`. No translation results were examined to choose these passages.

Compare the public v0.4.18 code, the first candidate (ec38132) and the revised candidate on exactly these inputs. Use the shipped local model, automatic field, a new browser context for each version and the default reading view. Report cold-inclusive median and P95, available translations, visible useful sentences, hidden useful sentences, severe visible errors and severe errors without a warning. A marker containing only the original text counts as unavailable in the target language. Two-sentence passages require both sentences for full passage credit. Preserve all failures.

For semantic review, strip version, display state and diagnostics. Grade each distinct source–translation pair once in shuffled order. Equal outputs share the same judgment. A useful sentence preserves the main relation, scientific object, relevant values and qualifications. A severe error changes one of those facts. An awkward sentence that remains unusable without changing a decisive fact is recorded separately. A missing sentence earns zero coverage. Infer exact UI visibility from the saved per-sentence issues and confirm the policy through the browser UI. Report the assessor and any limits of blinding. The 105 older passages are regression cases. Keep fresh passages out of development and never apply a prior judgment to new wording.

Use the existing release criteria, including at least 98% effective scientific coverage and zero unmarked severe errors in the sample. Engineering checks must independently pass. A small fresh sample can detect failures and does not establish population-level accuracy.
