## 逐条比较显示了什么

- 在温度和压力传感器摘录中，Bergamot 保留了采样频率、两个变化量及单位。OPUS 的两个配置均写作“毫米汞”，需改为“毫米汞柱”。[原文](https://doi.org/10.1364/OE.27.005641)
- 在生态学摘录中，Bergamot 将第二种鸟的样本量从 196 改为 16。OPUS 保留了数字，却把第一种鸟的个体数写作人数。核对同句出现的科学对象和数量才能区分这两类错误。[原文](https://doi.org/10.1002/ece3.70587)
- 高摩擦条件下的一项结果描述只涉及有跌倒史老年人的模型。Bergamot 把绊倒译成“旅行引起的跌倒”，OPUS 单束误成“出行引起的坠落”，四束又变成“绊脚石”。三个输出都应核对。[原文](https://doi.org/10.1038/s41598-024-81361-7)
- 糖化血红蛋白研究中的两个 5% 在 Bergamot 输出中均保留，改善和恶化的方向正确。OPUS 的两种解码配置都以空框代替百分数。[原文](https://doi.org/10.1038/s41746-021-00541-1)

## 测量与评分

Windows x64，Intel Core Ultra 7 155H，Chrome 158.0.8127.88，每轮新建浏览器进程。两个模型使用同一台机器、同一组选段和相同的预热句。Bergamot 使用随 0.4.18 发版的英中资源，配置一个 Worker。OPUS 使用 Transformers.js 2.17.2、ONNX Runtime Web 1.14.0 和单线程 WASM；按上游要求以真实词表中的简体中文语言 ID 5 作为首个输入词元。两个测试均直接调用本地引擎，术语替换、事实核验和网页交互不计入原始模型成绩。[Mozilla 运行时说明](https://firefox-source-docs.mozilla.org/toolkit/components/translations/resources/03_bergamot.html) · [OPUS 上游生成要求](https://huggingface.co/Helsinki-NLP/opus-mt-en-zh/blob/408d9bc410a388e1d9aef112a2daba955b945255/README.md)

权重预先下载到本机，浏览器始终通过 127.0.0.1 访问，实测模型资源均返回 HTTP 200。冷启动包含本机 HTTP 传输、WASM 装载与首句推理，不包含部署站点至用户设备的公网下载时延。热启动的 P50 为中位数，P95 采用最近秩法。主比较每引擎有 51 个热句计时。浏览器背景进程也在内存统计内，每约 100 ms 枚举浏览器进程树，使用 Windows GetProcessMemoryInfo，取运行期间的峰值减去装载前基线中位数。工作集跨进程可能重复计入共享页，专用提交衡量进程承诺的私有内存，两者不可相加。

选段来自九篇明确许可为 CC BY 4.0 的论文，覆盖生物力学、地球物理、化学材料、临床研究、光学、计算生物学、生态学等。摘录来自摘要，保留原文 XML 提取出的文字。实验前为每条冻结了核心事实核对点。主比较逐条随机排列两种译文，隐藏模型名称，写完判断和具体理由后解盲。追加的四束复测使用同一套核对点，评阅时已知模型。评分来自本次单一审阅方，属于工程验收抽样，不能推断其他论文的真实错误率。原始论文作者、来源、许可、输入、输出与判断一并保留。[逐条记录及计时](comparison.json)

## 部署取舍

两款模型均已在本机浏览器实际推理。若接入 OPUS，需要单独加载分词器、两份 ONNX 权重、ONNX 运行时，并正确指定简体目标语言词元。此次运行的 OPUS 首次所需静态资源为 Bergamot 的 2.28 倍，单束热句中位耗时约为其 15 倍。四束解码改善了一条例句的 GPEP 缩写保留，但仍会改写数值；这批样本得不出替换现有引擎的理由。本次未向产品引入新的运行时、模型文件、费用或第三方服务。[模型和候选术语来源的官方许可](terminology-sources.zh-CN.md)
